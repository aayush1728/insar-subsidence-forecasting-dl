# Boundaries

Put your AOI / mine lease boundary GeoJSON files here (WGS84, EPSG:4326).

Expected file: `mine_lease_boundary.geojson` (referenced in
`src/config.py` as `MINE_BOUNDARY_GEOJSON`).

If you can't find official Raniganj lease boundaries publicly, a
reasonable stand-in is to digitize a rough polygon around a known colliery
in QGIS using satellite basemap imagery as reference — note in your
write-up that boundaries are approximate/for demonstration if you do this.
